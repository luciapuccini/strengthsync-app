## Dev commands 
There's deliberately no unified root dev — these are separate long-running processes you run side-by-side while developing, not a single build/test task.

apps/api
> pnpm --filter @strengthsync/api dev

apps/ui
> pnpm --filter @strengthsync/ui dev

apps/workflows
> pnpm --filter @strengthsync/workflows dev:api and dev:worker


## Production
Once CI/CD passes I need local machine for workflows

> docker compose -f docker-compose.workflows.yml up -d --build
> docker compose -f docker-compose.workflows.yml down
